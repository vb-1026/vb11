Viloyatga Boramiz — project files

1. Extract this ZIP into a folder.
2. Keep index.html and the assets folder together.
3. Open index.html in a modern browser. For geolocation, some browsers require running a local server (for example, VS Code Live Server) or HTTPS.
4. An internet connection is required for online maps and the external map/globe libraries.

Important: this is a front-end prototype. Profiles and ride data are saved in this browser using localStorage; they are not synced between different devices/users and are not a production backend.
